supervised learning vs unsupervised learning
supervised learning is giving it input A and wanting output B while giving it examples to learn from. Learn from being given the right answer. It learns to take just the input and gives a reasonably accurate prediction. An example would be a spam filter that is trained by being shown spam and not spam that is accurately labeled so that it will learn what to identify as spam. Regression is predicting a number from infinitely large amount of outputs The second type of supervised learning is classification. It is different from regression because it tries to predict within a limited amount of outputs. Regression can output any number among an infinite group of numbers while classifications have to classify something into distinct groups. You can also take more than one input for both i assume but he only mentions it in the classification segment. Unsupervised learning is asking an algorithm to find something interesting or a pattern on its own without giving it labels. It could cluster the cancer diagnosis into separate clusters without knowing what those clusters actually mean. Unsupervised learning just takes inputs with no outputs and finds patterns in the data. The types are clustering, anomaly detection, and dimensionality reduction. Dimensionality reduction is compressing data using fewer numbers while keeping all the original information. Training set is a dataset that is used to train a model. x is the input variable or is also called a feature. The output or target variable is denoted as y. m is the total number of training example. To denote a single training example, you would name it as x, y. You can also denote it with i where i is a row in the table in the data. After being trained on a training set the model will learn a function denoted as f where it can take an input x and give a prediction denoted as y-hat. The regular y is a target. y-hat - y is the error and squaring it and adding the error for all values in a set and finding the average for every point by dividing by m or sometimes 2m, that is the cost function. The squared error cost function is the most common for linear regression. Gradient descent finds the local minimum in a graph. It slightly changes the variables and sees if the value decreases and does that until it finds a minimum. To implement gradiant descent you need to update the values simultaneously. Both w and b values must update at the same time so that the updated version doesn't affect the other variables value. If the learning rate in gradient descent is too small then the function will take a long time to find the values of w and b, but if it is too big than maybe it doesn't converge at all and just diverges. Even with fixed learning rates the derivative part of the gradient descent function will get smaller as we reach a local minima since the slope will get smaller so the steps will be smaller allowing it to cleanly reach the local minimum. Batch gradient descent uses all values in the training data at every step of gradient descent.
