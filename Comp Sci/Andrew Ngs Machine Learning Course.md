supervised learning vs unsupervised learning
supervised learning is giving it input A and wanting output B while giving it examples to learn from. Learn from being given the right answer. It learns to take just the input and gives a reasonably accurate prediction. An example would be a spam filter that is trained by being shown spam and not spam that is accurately labeled so that it will learn what to identify as spam. Regression is predicting a number from infinitely large amount of outputs The second type of supervised learning is classification. It is different from regression because it tries to predict within a limited amount of outputs. Regression can output any number among an infinite group of numbers while classifications have to classify something into distinct groups. You can also take more than one input for both i assume but he only mentions it in the classification segment. Unsupervised learning is asking an algorithm to find something interesting or a pattern on its own without giving it labels. It could cluster the cancer diagnosis into separate clusters without knowing what those clusters actually mean. Unsupervised learning just takes inputs with no outputs and finds patterns in the data. The types are clustering, anomaly detection, and dimensionality reduction. Dimensionality reduction is compressing data using fewer numbers while keeping all the original information.
