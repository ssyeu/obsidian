# CS Degree Self-Study Roadmap (No Gen-Ed)

A sequenced path through the core courses of a CS degree, with free/high-quality resources for each. Designed to be worked through roughly in order — later courses assume earlier ones.

---

## Phase 0: Math Foundations

### Calculus I & II
- **Resource:** MIT OCW 18.01 / 18.02, or Professor Leonard (YouTube) for a slower, thorough pace
- **Why:** Needed for algorithm analysis, ML, graphics

### Discrete Mathematics
- **Resource:** MIT OCW 6.042J (Mathematics for Computer Science)
- **Covers:** Logic, proofs, set theory, graph theory, combinatorics — arguably the single most important math course for CS
- **Alt:** "Discrete Mathematics and Its Applications" by Rosen

### Linear Algebra
- **Resource:** MIT OCW 18.06 (Gilbert Strang) or 3Blue1Brown's "Essence of Linear Algebra" for intuition first
- **Why:** Critical for ML, graphics, data science

### Probability & Statistics
- **Resource:** MIT OCW 6.041 or Khan Academy Statistics
- **Why:** ML, algorithms analysis, data-heavy work

---

## Phase 1: Programming Foundations

### Intro to Programming (CS1)
- **Resource:** CS50x (Harvard, free on edX) — covers C, Python, arrays, memory
- **Alt:** "Automate the Boring Stuff with Python"

### Intro to Programming II / Object-Oriented Programming (CS2)
- **Resource:** CS61B (UC Berkeley, free lectures + materials online) — Java-based, covers OOP + intro data structures

---

## Phase 2: Core CS

### Data Structures & Algorithms
- **Resource:** CS61B (continued) or MIT 6.006 (Introduction to Algorithms)
- **Book:** "Introduction to Algorithms" (CLRS) — the standard reference
- **Practice:** LeetCode / NeetCode 150 alongside coursework

### Computer Organization & Architecture
- **Resource:** CS61C (UC Berkeley, free online) — covers assembly, how a CPU actually works
- **Book:** "Computer Organization and Design" (Patterson & Hennessy)

### Systems Programming (C, memory management)
- **Resource:** CS107/CS107E (Stanford, materials often public) or "The C Programming Language" (K&R)

---

## Phase 3: Theory

### Theory of Computation / Automata
- **Resource:** MIT OCW 18.404J or "Introduction to the Theory of Computation" (Sipser)
- **Covers:** Finite automata, Turing machines, decidability, NP-completeness

### Algorithms Analysis
- **Resource:** MIT 6.006 / 6.046J (Design and Analysis of Algorithms)
- **Covers:** Greedy, DP, graph algorithms, NP-completeness in depth

---

## Phase 4: Systems

### Operating Systems
- **Resource:** MIT 6.828 (Operating System Engineering) or OSTEP ("Operating Systems: Three Easy Pieces" — free online, excellent)
- **Project:** Build a toy OS or shell in C

### Computer Networks
- **Resource:** Stanford CS144 (has a public version with labs) or "Computer Networking: A Top-Down Approach" (Kurose & Ross)

### Databases
- **Resource:** CMU 15-445 (Database Systems, full lectures + assignments free on YouTube — excellent and current)
- **Covers:** SQL, query optimization, transactions, indexing, storage engines

---

## Phase 5: Software & Applied

### Software Engineering
- **Resource:** Build a full project using version control, testing, CI — "Missing Semester" (MIT) covers the practical tooling side
- **Practice:** Contribute to an open-source project

### Programming Languages
- **Resource:** University of Washington's "Programming Languages" course (Dan Grossman, free on Coursera) — covers functional, OOP, and language design tradeoffs

---

## Phase 6: Specialization (pick 1–2 tracks)

- **AI/ML:** Andrew Ng's Machine Learning Specialization (Coursera) + fast.ai for practical deep learning
- **Security:** MIT 6.858 (Computer Systems Security)
- **Compilers:** Stanford CS143 or "Crafting Interpreters" (free online book, very approachable)
- **Distributed Systems:** MIT 6.824
- **Graphics:** UC San Diego CSE 167 or "Learn OpenGL" tutorials
- **Web/Mobile:** Full Stack Open (free, University of Helsinki)

---

## Phase 7: Capstone

- Build one substantial project that ties together systems + algorithms + software engineering practice — e.g., a database engine, a compiler, a distributed key-value store, or your own ML pipeline
- Document it like a real engineering project: design doc, tests, README

---

## Suggested Pacing

| Phase | Rough Duration |
|---|---|
| 0 – Math Foundations | 3–4 months (can overlap with Phase 1) |
| 1 – Programming Foundations | 2–3 months |
| 2 – Core CS | 4–6 months |
| 3 – Theory | 2–3 months |
| 4 – Systems | 4–6 months |
| 5 – Software & Applied | 2 months |
| 6 – Specialization | 3+ months |
| 7 – Capstone | 1–2 months |

**Total: roughly 18–24 months at a serious, sustained self-study pace** (part-time alongside other work would take longer).

---

*Tip: LeetCode/algorithm practice should run continuously in the background from Phase 2 onward, not as a separate phase.*
